# Streamlining IT Procurement Automating Standard Laptop Orders with Flow Designer
The Standard Laptop Task flow automates the creation of a Catalog Task for Standard Laptop requests. Once the request reaches the configured approval condition, the flow creates a task under the related Requested Item and assigns it to the Hardware assignment group for laptop configuration.

Purpose: To reduce manual task creation, improve processing speed, and ensure approved laptop requests are automatically routed to the appropriate team.
